# Local dev & browser testing

How to start the three services locally and how to verify the UI in a real
browser (including a headless-Chromium path for locked-down hosts that lack
`apt`/root).

All commands run from the **repo root** unless stated otherwise.

## 1. Install dependencies (once)

```bash
npm ci          # hoists all workspace deps to root node_modules/
```

## 2. Start the services

Three processes, each in its own terminal (or detached, see below):

| Service | Command | Port | Notes |
|---------|---------|------|-------|
| Server  | `node server.js` (in `buraco-server/`) | 8000 | game lobby + boardgame.io |
| Client  | `npm run dev -w buraco-client` | 5173 | Vite dev server |
| Bot     | `node bot.js` (in `buraco-server/`) | — | polls the lobby, claims "bot" seats |

The bot needs to reach the server. Outside Docker the hostname `buraco-server`
does not resolve, so point it at localhost:

```bash
EUCHRE_SERVER_URL=http://localhost:8000 MIGHTY_SERVER_URL=http://localhost:8000 node bot.js
```

### Detached (survives a wrapping shell / tool timeout)

`nohup ... &` and `setsid ...` get killed when the calling shell returns.
Use the double-fork launcher instead:

```bash
python3 scripts/detach.py buraco-server server.log node server.js
python3 scripts/detach.py buraco-server bot.log    node bot.js
```

Find the PID later (no `ps`/`pgrep` on locked-down hosts):

```bash
for p in $(ls /proc | grep -E '^[0-9]+$'); do
  tr '\0' ' ' < /proc/$p/cmdline 2>/dev/null | grep -q 'node server.js' && echo "server pid $p"
done
```

Stop with `kill <pid>`.

## 3. Verify the rules engine (no browser needed)

The repo has ad-hoc node harnesses at the root (there is no test framework):

```bash
node test-euchre-engine.mjs
node test-euchre-match.mjs
node test-euchre-bot.mjs
```

For a one-off check of a pure export, import it directly and neutralize the
WASM meld-sync hook:

```js
import { moveMeld, generateAllValidMelds } from '@buraco/game/Buraco.js';
```

## 4. Verify the UI in a browser

### Interactive (a real browser)

Open http://localhost:5173, click **Quick Game**, pick a game, **Start Match**.
The bots claim the remaining seats automatically.

### Headless (Playwright) — the scripts in this folder

`scripts/drive-euchre-browser.mjs` starts a Euchre quick game, plays the human
seat (pass on bids, name trump if forced, handle the call, click legal cards),
and stops when the trick-history panel renders. It prints the panel's grid DOM
and saves a screenshot.

```bash
node scripts/drive-euchre-browser.mjs
# or
CLIENT_URL=http://localhost:5173 SHOT=/tmp/board.png node scripts/drive-euchre-browser.mjs
```

It uses `import { chromium } from 'playwright'`, so Playwright must be
installed with its Chromium build:

```bash
npx playwright install chromium
# if you have root, this also installs the system deps:
npx playwright install --with-deps chromium
```

**On this host the Chromium system libraries, `fontconfig`, and fonts are
already installed system-wide** (verified 2026-09-14), so the driver runs with
**no extra env vars** — just `node scripts/drive-euchre-browser.mjs`. The
locked-down-host fallback below is only needed on a host that lacks these.

### Headless on a locked-down host (no apt / no root)

Headless Chromium needs several shared libraries and a fontconfig setup. If
they are missing, the browser either fails to launch or renders blank.

**Option A — install the real packages (preferred, needs root):**

```bash
apt-get install -y \
  libglib2.0-0 libnss3 libnspr4 libatk1.0-0 libatk-bridge2.0-0 \
  libatspi2.0-0 libdbus-1-3 libx11-6 libxcomposite1 libxdamage1 libxext6 \
  libxfixes3 libxrandr2 libxcb1 libxkbcommon0 libxau6 libxdmcp6 libxi6 \
  libxrender1 libgbm1 libasound2 libdrm2 libatomic1 \
  fontconfig libfontconfig1 fonts-dejavu-core
```

Then run the driver with no extra env vars (system fontconfig finds the fonts).

**Option B — no root: extract the libs locally:**

```bash
bash scripts/fetch-chromium-libs.sh          # extracts into scripts/.chromium-libs
export LD_LIBRARY_PATH=$(ls -d scripts/.chromium-libs/*/usr/lib/x86_64-linux-gnu | tr '\n' ':')
export FONTCONFIG_FILE=$PWD/scripts/fonts.conf   # regenerated by the fetch script
export FONTCONFIG_PATH=$PWD/scripts/.chromium-libs/fc-cache
node scripts/drive-euchre-browser.mjs
```

`fetch-chromium-libs.sh` downloads the `.deb` files from `deb.debian.org`
(via `python3`, no `curl` needed) and extracts them with `dpkg-deb`. It also
rewrites `scripts/fonts.conf` with the absolute font path.

## 5. System dependencies checklist

These are required for headless Chromium (and general troubleshooting). **All
of them are now installed on this host** (verified 2026-09-14: `curl` 8.14.1,
`libglib-2.0.so.0` present, `fc-list` with 50 fonts, full Playwright
Chromium). The list below is the reference set to install on a host that
lacks them:

- `curl` — HTTP client (the scripts use `python3 urllib` as a fallback, so
  `curl` is optional but convenient).
- `libglib2.0-0` — provides `libglib-2.0.so.0`, a core Chromium dependency.
- `fontconfig` + `libfontconfig1` + `fonts-dejavu-core` — Chromium needs
  fontconfig to render text; without fonts the page renders blank.
- The rest of the Chromium runtime: `libnss3`, `libnspr4`, `libatk1.0-0`,
  `libatk-bridge2.0-0`, `libatspi2.0-0`, `libdbus-1-3`, `libx11-6`,
  `libxcomposite1`, `libxdamage1`, `libxext6`, `libxfixes3`, `libxrandr2`,
  `libxcb1`, `libxkbcommon0`, `libxau6`, `libxdmcp6`, `libxi6`, `libxrender1`,
  `libgbm1`, `libasound2`, `libdrm2`, `libatomic1`.

If `npx playwright install --with-deps chromium` is available (needs root), it
installs all of the above automatically.
